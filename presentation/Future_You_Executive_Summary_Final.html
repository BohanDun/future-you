Future You

A conversational financial simulator — helping customers explore what could happen next.

The problem

Banking tools show customers what happened to their money, but not how today’s decision could affect tomorrow’s cash flow, financial buffer and personal goals. Customers are left guessing before purchases, savings changes or rising recurring costs.

The solution

Future You turns a plain-English “what-if” question into a quantified, before-and-after simulation grounded in the customer’s saved plan. AI understands and explains; deterministic Python code calculates every displayed financial figure.

Financial dashboardShows balance, monthly income, monthly expenses, monthly cash flow, spending categories and savings goals.
Advice modeRuns read-only scenarios and explains the trade-off without changing the saved customer plan.
Manage modePreviews an exact proposed change and requires explicit confirmation before validated data is saved.

How it works

React frontend → Amazon Cognito sign-in and JWT → Amazon API Gateway → FastAPI on AWS Lambda → Amazon DynamoDB customer profile → Amazon Bedrock interprets and explains → deterministic financial engine calculates cash flow, goal timing and risk.
